# Customer Churn ML

An end-to-end machine-learning project for predicting customer churn from tabular data.

## Objective

Build an interpretable and reproducible classification pipeline that identifies customers at risk of churn.

## Planned workflow

1. Data validation and exploratory analysis
2. Feature preprocessing
3. Baseline and tree-based model comparison
4. Cross-validation and leakage prevention
5. Experiment tracking with MLflow
6. Model interpretation with SHAP
7. Reproducible tests and documentation

## Tech stack

Python, pandas, scikit-learn, MLflow, SHAP, pytest, GitHub Actions.
